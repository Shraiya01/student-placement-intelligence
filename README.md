# Student Placement Intelligence & Career Readiness Analytics

## 📌 Project Overview

This project analyzes student placement data to understand
placement trends, department-wise performance, and career
readiness factors.

## 🛠️ Tools Used

- Microsoft Excel
- MySQL
- Power BI

## 📊 Dataset

The dataset contains student academic, skill, internship,
and placement-related information.

## 🔍 Analysis

- Overall placement rate
- Department-wise placement performance
- Internship and skill analysis
- Career readiness indicators

Insights will be added after completing the analysis.
